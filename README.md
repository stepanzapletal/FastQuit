## ✨ Features

**FastQuit** is designed to help you break bad habits with a clean, distraction-free interface. It respects your privacy and looks great on your phone.

* **🎨 Material You Design:** Fully adaptive UI that pulls colors from your wallpaper (Android 12+).
* **📴 Offline First:** All your data stays on your device. No accounts, no tracking.
* **⚡ Smart Haptics:** Satisfying tactile feedback when interacting with the app.
* **🔄 Built-in Updater:** Automatically checks GitHub for new features and updates.
* **💬 Daily Motivation:** Get motivational quotes to keep you on track.
* **🌑 Dark Mode:** Native dark mode support for late-night usage.
* **🇨🇿 Multilingual:** Available in English and Czech.

## 📥 Download & Installation

FastQuit is not on the Play Store. You can download the latest version directly from GitHub.

1.  Go to the **[Releases Page](https://github.com/stepanzapletal/FastQuit/releases/latest)**.
2.  Download the latest `.apk` file.
3.  Open the file on your Android device.
4.  If prompted, allow installation from **Unknown Sources**.
5.  Enjoy! (and good luck!)

*> **Note:** The app includes an automatic update checker. When a new version is released on GitHub, the app will notify you.*

## 🛠️ Tech Stack

* **Language:** Kotlin
* **UI:** Jetpack Compose (Material 3)
* **Architecture:** MVVM
* **Networking:** Retrofit (GitHub API integration)
* **Local Storage:** Room Database & DataStore
* **Iconography:** Material Icons
